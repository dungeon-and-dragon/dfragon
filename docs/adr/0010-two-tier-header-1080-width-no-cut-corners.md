# ADR 0010: 상단 바를 전역 바와 게임 바 2단으로 나누고 콘텐츠 폭 1080px, 자른 모서리 없음을 화면에 적용한다

## 상태

채택. [ADR 0009](0009-design-tokens-game-site-conventions.md)가 값만 정하고 화면 적용을 미룬 항목 가운데 상단 바 높이와 2단 구조, 콘텐츠 폭, 자른 모서리를 정한다. ADR 0009를 대신하지 않고 그 결정의 화면 적용을 기록한다.

## 맥락

ADR 0009는 게임 전적 사이트의 관습에서 전역 바 48px + 게임 바 40px 2단 헤더와 콘텐츠 폭 1080px을 골랐다. 그러나 웹 앱은 상단 바를 `TopBar`의 44px 직접 값으로 그리고, 상단 바와 화면을 파티 1280×163, 공대 1280×300 상자에 합성하고 있었다. 상자 높이는 상단 바 44px에 파티 카드 영역 119px, 공대 카드 3줄 영역 256px을 더한 값이다.

상단 바 한 줄에는 등급 퍼센트, 제품 이름, 검색 메뉴, 화면 헤더(보드 제목, 알림, 캡처 시각, 스냅샷, 복사, 캡처 버튼), 게임 연결 칩이 모두 들어 있었다.

자른 모서리(`shapes.cutTopRight`, `shapes.cutBottomRight`, `--df-cut`)는 이전 던삐삐 디자인의 특징으로, 주 버튼, 상태 칩, 화면 헤더 도구 버튼, 작은 서버 선택, 목록 열림 모양, 검색 메뉴, 후보 칩, 공대 파티 번호, 복사 버튼, 스냅샷 칩, 스냅샷 확인 팝업, 실패 표시에 쓰였다. `clip-path`가 바깥 포커스 링을 가리므로 주 버튼, 도구 버튼, 검색 메뉴, 복사 버튼은 포커스 링을 면 안쪽에 그렸다. 소유자가 고른 초안 화면과 조사한 다섯 사이트에는 자른 모서리가 없고 0~4px 모서리만 있다.

인식과 캡처 코드는 웹 앱 상자의 크기를 읽지 않는다. 상자 크기가 바뀌어도 화면 공유와 붙여넣기의 인식 결과는 같다.

## 결정

| 항목 | 결정 | 값 |
| --- | --- | --- |
| 상단 바 높이 | 전역 바가 `size.topbar` 토큰을 읽는다 | 48px |
| 상단 바 구조 | 전역 바와 게임 바 2단. 전역 바에 등급 퍼센트, 제품 이름, 게임 연결 칩을 두고, 게임 바에 검색 메뉴와 화면 헤더를 둔다 | 전역 바 48px, 게임 바 40px |
| 콘텐츠 폭 | 웹 앱 상자를 1080px로 줄인다 | 파티 1080×207, 공대 1080×344 |
| 자른 모서리 | 없앤다. 버튼, 칩, 도구 버튼, 배지는 컨트롤 반지름 2px, 팝업과 패널은 0 | `shapes.cutTopRight`, `shapes.cutBottomRight`, `shape.cut`, `--df-cut` 삭제 |

- 상자 높이는 상단 바가 커진 만큼만 늘리고 카드 영역 높이는 그대로 둔다. 공대 카드 3줄은 스크롤 없이 들어간다.
- 1080px에서 카드 폭은 파티 약 300px에서 약 250px, 공대 약 306px에서 약 256px으로 줄어든다. 긴 이름, 길드, 직업은 더 일찍 말줄임된다.
- 자른 모서리 때문에 면 안쪽에 그리던 포커스 링은 공용 바깥 링(신호색 2px, 간격 2px)으로 되돌린다.
- 목록이 열리고 닫히는 모양은 자른 다각형 대신 위에서 아래로 펼치는 사각형(`inset`)으로 바꾼다.
- 게임 바의 검색 메뉴는 바 높이를 채우고 현재 항목의 신호색 밑줄이 바 아래쪽에 닿는다.

## 정하지 않은 것

- 카드 상태 면(랭커 카드 배경 `tierRankerSurface`, `tierRankerWell`, 검색 실패의 옅은 면 `cardFailureWeak`)은 유지하며 없앨지는 ADR 0009와 같이 후속으로 둔다.
- 글꼴(마루미냐 한글과 Pretendard, 숫자 글꼴 Barlow Condensed)은 이 결정의 범위가 아니다.
- 게임 바 높이 40px은 상단 바 한 곳만 쓰는 값이라 토큰으로 만들지 않고 `TopBar` 스타일에 둔다.
- dfragon-design `tokens.json`에서 자른 모서리 토큰을 지우는 일은 그 저장소의 PR로 한다.

## 결과

- `packages/client`의 상단 바가 전역 바와 게임 바 두 줄이 되고 웹 앱 상자가 1080×207, 1080×344로 바뀐다. `apps/web`의 대기 상자도 같은 크기로 바뀐다.
- `@dfragon/ui`의 공개 `shapes`에서 `cutTopRight`, `cutBottomRight`가, `tokens.stylex`의 `shape`에서 `cut`이, `tokens.css`에서 `--df-cut`이 사라진다. 저장소 밖 소비자는 없다.
- 규칙 문서의 형태, 크기 항목과 웹 클라이언트 Rule, `apps/web`, `packages/ui` README의 크기와 자른 모서리 설명이 이 결정을 따른다.

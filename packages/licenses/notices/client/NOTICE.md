# 던삐삐 웹 클라이언트 UI 자산

- Pretendard Variable: Pretendard 1.3.9 npm 패키지(https://www.npmjs.com/package/pretendard/v/1.3.9 , 저장소 https://github.com/orioncactus/pretendard )의 `dist/web/variable/woff2/PretendardVariable.woff2`를 수정 없이 `packages/client/src/assets/fonts`에 둡니다. SHA-256: `9599f12fd42fc0bce1cd50b47a0c022e108d7aa64dd0d1bb0ed44f3282d900b4`. Kil Hyung-jin의 글꼴이며 같은 패키지의 `dist/LICENSE.txt`(SHA-256 `b04538c9abec39a3db75108cf0af0fd9c77032fe8aa2cf38345b4d250e98e38e`)인 OFL 1.1 전체 고지는 같은 폴더의 `PRETENDARD-LICENSE`에 있습니다.
- 카메라, 테마 전환(해, 달), 새 버전 Release 열기, 캡처 창 선택(모니터, 체크, 화살표, 새로고침) SVG: Lucide 형태를 사용합니다. 출처: https://lucide.dev/icons . ISC와 Feather 파생 아이콘의 MIT 고지는 같은 폴더의 `LUCIDE-LICENSE`에 있습니다.
- 공대 상세 창 검출 기준 헤더: 사용자가 제공한 던전앤파이터 화면에서 UI 0%의 열 제목, 구분선, 배경(423×18px)만 추출한 게임 UI 자산입니다. 권리는 NEOPLE/NEXON에 있으며 별도 오픈소스 라이선스를 부여하지 않습니다. 닉네임, 공대 제목, 플레이어 이미지는 포함하지 않습니다. `packages/client-core/src/shared/raid/raid-heading.png`에 무손실 PNG로 보관하며, 공대 캡처의 템플릿 비교에 사용합니다.
- 공대 상세 창 수치 열 제목 기준 이미지: 사용자가 제공한 던전앤파이터 1067×600 화면에서 UI 0%의 수치 열 제목 칸 두 개("명성", "장비 점수", 각 75×18px)만 추출한 게임 UI 자산입니다. 권리는 NEOPLE/NEXON에 있으며 별도 오픈소스 라이선스를 부여하지 않습니다. 닉네임, 공대 제목, 직업명, 플레이어 이미지는 포함하지 않습니다. `packages/client-core/src/shared/raid/raid-value-heading-fame.png`, `raid-value-heading-equipment-score.png`에 무손실 PNG로 보관하며, 공대 캡처의 수치 열 판독과 공대 행 판독 오프라인 평가에 사용합니다.
- 공대 상세 창 수치 글자 기준 이미지: Windows 돋움 글꼴(`gulim.ttc` 글꼴 번호 2)을 dnf-ocr-synth(https://github.com/dungeon-and-dragon/dnf-ocr-synth , commit `809df79`)로 UI 0% 크기에 렌더링한 `0`~`9`, 쉼표, 소수점, `K` 글자(높이 17px)입니다. 글꼴 파일은 포함하지 않으며 글꼴의 권리는 저작권자에게 있습니다. `packages/client-core/src/shared/raid/raid-value-glyphs.png`에 글자를 이어 붙인 무손실 PNG 한 장으로 보관하며, 공대 캡처의 수치 판독과 공대 행 판독 오프라인 평가에 사용합니다.

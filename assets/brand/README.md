# 던삐삐 아이콘

`dfragon.png`는 던삐삐 공통 아이콘 원본입니다. 시간대별 창 아이콘 중 낮 그림과 같은 픽셀 아트 바다 풍경(1024×1024, 배경까지 채운 정사각형)이며, 앱에 필요한 크기와 형식만 변환합니다(2026-10-30 사용자 요청).

의존성 설치 후 저장소 루트에서 다음 명령으로 파생 파일을 갱신합니다. 원본을 `pngjs`로 읽어 16×16 픽셀 칸마다 RGBA 평균을 내 64×64로 줄입니다.

```sh
node scripts/generate-brand-icons.mjs
```

- Web `public/favicon.png`: 사이트 상단 바의 아이콘과 파비콘
